# Changes in 0.12.3 (2026-11-23)

Documentation and packaging only: the plugin's behaviour is unchanged from 0.12.2.

- **New screenshots** of every tool in `docs/` (the old ones were out of date): the name wheel, two wheels, both winners together, the group generator, stopwatch, timers with the sound choice, counters, scoreboard and the activity settings.
- **README**: shows the new screenshots, has a new Requirements section (Moodle 5.0 to 5.3, PHP 8.2 to 8.4, no third-party libraries or external services) and a Support section linking the issue tracker.
- **Release zips** no longer contain the CI workflow folder (`.gitattributes`).
- No database changes (version number bump only).
