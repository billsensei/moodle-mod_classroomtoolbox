# Changes in 0.8.8 (2026-11-23)

- **Timer alarm**: the dive klaxon is a little louder again. Each blast's peak volume went from 0.4 to 0.48, which raised the average level by about 1.6 dB (measured with the browser's audio engine) with the peak still just below clipping (0.95 of 1.0). This is about as loud as the horn can get without distorting. The Sound switch still silences it.
- No database changes (version number bump only).
