This files describes API changes in /mod/classroomtoolbox/*,
information provided here is intended especially for developers.

=== 0.12.0 ===
* The "Pick partners" switch of 0.11.0 was replaced by an "Add second wheel" button on the name wheel tab. The
  mod_classroomtoolbox/wheel module now makes each wheel as its own unit (canvas, spin, names list) and shares the winner
  dialog, group chooser and sound switch. The wheel template has data-region attributes wheel-unit, wheel-stagecol and
  wheel-namescard that the script copies for the second wheel. The partner_* language strings were removed and wheel_*
  strings added. classroomtoolbox_replace_partner_tool() is kept for activities that still list the old tool.

=== 0.11.0 ===
* The separate 'partners' tool added in 0.10.0 was removed again: the partner wheel is now a "Pick partners" switch on the
  name wheel tab (mod_classroomtoolbox/wheel, templates/wheel.mustache). classroomtoolbox_replace_partner_tool() turns
  a stored 'partners' tool into 'wheel' on upgrade.
* mod_classroomtoolbox/sound: alarm() was replaced by play(kind, force) and the list KINDS (siren, beeps, clock, klaxon,
  futuristic, duck). Each timer chooses its sound; the choice is stored with the other timer settings in the browser.
* The timer template carries the sound chooser in a <template> element that the timer script copies into each card.

=== 0.10.0 ===
* New tool 'partners' (class \mod_classroomtoolbox\local\tools\partners, extends tools\wheel) is registered in
  toolbox::classes() after the wheel. The wheel template and the mod_classroomtoolbox/wheel module take a region name
  ('wheel' or 'partners') and a partner mode, so two wheels can be on one page.
* New AMD module mod_classroomtoolbox/store keeps each tool's settings in the browser's localStorage, per activity
  (the toolbox template has a data-storekey attribute set to the course module id).
* The timer alarm is now a siren; it only uses plain oscillators.

=== 0.9.0 ===
* The toolbox is now a teacher-only tool. The capability mod/classroomtoolbox:view is no longer granted to the student
  archetype, and the upgrade step removes it from roles of the student archetype on existing sites. Grant it to a role
  yourself if some other users should open the toolbox.
* New classroomtoolbox_cm_info_dynamic() hides the activity from users without that capability.
* FEATURE_COMPLETION_TRACKS_VIEWS is no longer supported (students never open the toolbox).

=== 0.8.0 ===
* New AMD modules mod_classroomtoolbox/sound (Web Audio sounds and the shared sound preference) and
  mod_classroomtoolbox/colour (readable text colour for a background colour).
* The Colour scheme setting now also colours the group generator's cards. The 'text' key was removed from
  classroomtoolbox_color_schemes(): the scripts pick white or dark text per colour.
* The privacy provider is now a full provider (metadata plus request provider) instead of a null provider. It still
  links nothing to a user account. Deleting all data in an activity context now clears that activity's scoreboard.
* Capability mod/classroomtoolbox:managescores now carries RISK_SPAM.
* The external function mod_classroomtoolbox_get_scores is marked readonlysession.

=== 0.7.0 ===
* New table classroomtoolbox_scores, capability mod/classroomtoolbox:managescores, event
  \mod_classroomtoolbox\event\scoreboard_changed and six AJAX-only external functions
  (mod_classroomtoolbox_get_scores, add_scores, change_score, update_score, delete_score, reset_scores).

=== 0.5.0 ===
* Renamed from mod_namewheel to mod_classroomtoolbox. Tools are classes implementing
  \mod_classroomtoolbox\local\tool_interface, listed in \mod_classroomtoolbox\local\toolbox.
* cli/migrate_from_namewheel.php moves existing Name wheel activities across.
